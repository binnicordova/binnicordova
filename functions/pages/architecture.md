# React Native Architecture & Mobile Skills — Binni Cordova

Five systems that shipped in production — at Coca-Cola, NFL+, Itau Bank, Platanitos, and Gruppo GPI — each diagrammed exactly as built, not a reference architecture copied from a blog post.

## 1. Coca-Cola — Marketplace: Offline-First + BFF (Apr 2025 – Present)
Redesigned a client that broke down in low-connectivity conditions into an offline-first system, and moved business logic off-device onto an AWS Backend-for-Frontend — the pattern currently in production. Stack: React Native, Swift/Kotlin, AWS Lambda, offline sync.

## 2. NFL+ CTV — Cross-Platform Streaming Player (Feb 2024 – Mar 2025)
One React Native core powering Mobile, Web, and Smart TV, with a native TheoPlayer bridge per platform — built to cut startup time, memory, and JS↔native bridge traffic at millions-user scale. Stack: React Native, TheoPlayer, Smart TV, Live + VOD.

## 3. Itau Bank ITU — Secure Banking App + Delivery Pipeline (Dec 2021 – Feb 2024)
Biometric-secured mobile banking for 100K+ users, backed by a CI/CD pipeline built to hold 90%+ automated test coverage without slowing releases. Stack: Biometrics, Keychain/Keystore, mTLS, CI/CD.

## 4. Platanitos — Legacy-to-Mobile Commerce Migration (Mar 2019 – Dec 2021)
Led the move from a legacy web storefront to React Native + Expo — search, payments, and push notifications wired end-to-end, shipped through an EAS pipeline to three app stores, surpassing 1M+ downloads. Stack: React Native, Expo/EAS, Algolia, Mercado Pago.

## 5. Gruppo GPI — Clinical Reporting & Annotation System (Mar 2018 – Mar 2019)
Reusable JavaScript and Java components feeding a Jasper Reports pipeline, deployed across a distributed hospital network of 3,000+ hospitals and clinics in Italy and Germany.
